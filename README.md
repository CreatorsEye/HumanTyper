# 🚀 Creators Eye Auto Typer

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Windows](https://img.shields.io/badge/Platform-Windows-blue)](https://github.com/yourusername/CreatorsEye-AutoTyper)

A human‑like typing automation tool that types text exactly as written – preserving line breaks, spacing, and formatting. Available in two versions:

| Version | Description | Requirements |
|---------|-------------|--------------|
| 🖥️ **CLI** | PowerShell script | Windows 7+ (PowerShell 5.1+) |
| 🎨 **GUI** | Compiled executable | Windows 7+ (64‑bit), no .NET needed |

👉 **GUI executable** is hosted on [Archive.org](https://archive.org/details/creators-eye-human-typer) (~60 MB).

---

## ✨ Common Features

- Configurable typing speed (5 levels)
- Mistake simulation (6 levels, including random)
- Preserves line breaks (sends ENTER key)
- Paste from clipboard / Import from Notepad
