## 🚀 How to use

### Option 1: Download EXE (no build needed)
1. Click **Download** link for any version
2. Run the EXE file
3. No installation required

### Option 2: Browse source code
1. Click **Source** link for any version
2. View or download the C# code
3. Build with `dotnet publish`

---

## 📋 Requirements

- Windows 10 or 11
- .NET 8.0 Runtime (to run EXE) or SDK (to build)
