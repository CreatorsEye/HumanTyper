# 👨‍💻 Developer Guide – Learn by Reading Code

## 🎯 Purpose

This is not just a tool. It's a **learning resource**.

From **v1.0** to **v2.0**, each version adds **exactly one new feature**.

You can see **how** the code evolves, **why** changes are made, and **what** each version teaches.

---

## 📚 What Each Version Teaches

### v1.0 – The Foundation
- Windows Forms basics
- SendInput API for Unicode characters
- Async/await for delays
- **Files:** `Program.cs`, `MainForm.cs`

### v1.1 – Control Logic
- Stop, Pause, Resume buttons
- Threading and state management
- Console output (RichTextBox)

### v1.2 – User Settings
- ComboBox for speed selection
- Dynamic delay adjustment

### v1.3 – System Integration
- Global hotkeys (RegisterHotKey API)
- WndProc override for hotkey messages

### v1.4 – Text Processing
- Multi-line support (preserving `\n`)
- Sending Enter key via SendInput

### v1.5 – Persistence & Isolation
- Customizable hotkeys saved to `hotkeys.cfg`
- Mutex for single instance

### v1.6 – Randomization
- Mistakes simulation (typo generation)
- Random number generation

### v1.7 – Conditional Logic
- Fix Typo control (Yes/No)
- Conditional correction

### v1.8 – Realistic Timing
- Human-like delays (300-600ms pause)
- Natural backspace timing

### v1.9 – Window Management
- Auto stay-on-top during typing only
- TopMost property toggling

### v2.0 – Professional UI
- Borderless form
- Custom title bar (minimize/close buttons)
- Modern dark theme

---

## 🚀 How to Study This Project

1. **Start with v1.0** – Understand the basics
2. **Compare v1.0 and v1.1** – See what changed
3. **Continue through each version** – One feature at a time
4. **Build your own ideas** – Use this as a foundation
