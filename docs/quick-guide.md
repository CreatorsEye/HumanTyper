# Quick Guide - Creators Eye Human-Like Typer

## 📋 Menu Options At A Glance
Input text via Notepad → Open notepad to write/paste text

Paste from Clipboard → Load text you already copied

Load default text → Use built-in sample text

Preview text → See what text is loaded

Change speed → Very Slow to Very Fast

Change mistakes → 0 to 10+ mistakes

Configure hotkeys → Change F8-F11 keys

Reset to defaults → Back to original settings

START TYPING → Begin automated typing

Exit → Close program

## 🎮 Default Hotkeys (While Typing)

| Press | Action |
|-------|--------|
| F8 | Pause typing |
| F9 | Resume typing |
| F10 | Stop completely |
| F11 | Show status |

## ⚡ Speed Levels

- **Very Slow**: 200-300ms per character
- **Slow**: 120-200ms per character  
- **Medium**: 60-120ms per character
- **Fast**: 30-70ms per character
- **Very Fast**: 15-40ms per character

## ❌ Mistake Levels

- **0**: No mistakes
- **1**: 1-2 mistakes
- **2**: 3-4 mistakes
- **3**: 5-7 mistakes
- **4**: 8-10 mistakes
- **5**: Random amount

## 🎯 Quick Start (30 seconds)

1. Run the script
2. Press **3** (Load default text)
3. Press **9** (START TYPING)
4. Click on Notepad or any text field
5. Watch it type!

## 💡 Tips

- Always test in Notepad first
- Hotkeys only work when PowerShell window is active
- You can change settings anytime
- Use F8 to pause if you need to interrupt
