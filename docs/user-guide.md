## 🚀 Quick Start (5 Steps)

### Step 1: Launch the App
- Double-click `CEautoTyper.exe`
- No installation needed
- If Windows shows a warning → click **"More info"** → **"Run anyway"** (it's safe)

### Step 2: Enter Your Text

| Method | How to |
|:---|:---|
| **Type directly** | Just type in the large text box |
| **Paste from clipboard** | Copy text (Ctrl+C), then click the **Clipboard** button |
| **Use Notepad** | Click **Notepad**, type there, save and close |

### Step 3: Choose Settings
- **Speed:** Very Slow / Slow / Medium / Fast / Very Fast
- **Mistakes:** None / Few / Some / Many / Lots / Random
- **Fix Typo:** Yes (corrects mistakes) / No (leaves typos)

### Step 4: Start Typing
- Click **START TYPING** or press **F5**
- You have **5 seconds** to click on your target window
- Click anywhere you want the text to appear (Notepad, browser, Word, etc.)

### Step 5: Control While Typing

| Button | What it does |
|:---|:---|
| **PAUSE** | Temporarily stops typing |
| **RESUME** | Continues typing from where it paused |
| **STOP** | Ends the typing session immediately |
| **Set Hotkeys** | Change keyboard shortcuts |

## ⌨️ Default Hotkeys (Work Anywhere)

| Key | Action |
|:---|:---|
| `F5` | Start typing |
| `F8` | Pause |
| `F9` | Resume |
| `F10` | Stop |

> Hotkeys work even when the window is not focused.  
> You can change them anytime with the **Set Hotkeys** button.

## ⚙️ Settings Explained

### Speed Levels

| Level | Delay per character |
|:---|:---|
| 🐢 Very Slow | 250-450 ms |
| 🚶 Slow | 150-250 ms |
| ⚡ Medium | 80-160 ms |
| 🏃 Fast | 40-90 ms |
| 🚀 Very Fast | 15-45 ms |

### Mistake Levels

| Level | Number of mistakes |
|:---|:---|
| ✅ None | 0 |
| 🔹 Few | 1-2 |
| 🔸 Some | 3-4 |
| ⚠️ Many | 5-7 |
| ❗ Lots | 8-10 |
| 🎲 Random | Random (1-10) |

### Fix Typo

| Setting | What happens |
|:---|:---|
| **Yes** | Types wrong word → backspace → corrects it |
| **No** | Types wrong word and leaves the mistake |

## 💡 Pro Tips

- **Test first** – Try typing into Notepad to see how it works
- **Use clipboard** – Fastest way to load large amounts of text
- **Save templates** – Keep common text in a file and paste when needed
- **Custom hotkeys** – Avoid conflicts with other apps
- **Pause before switching windows** – Gives you time to focus the target

---

## ❓ Troubleshooting

| Problem | Solution |
|:---|:---|
| Nothing happens when I click START | You forgot to click the target window during the 5-second countdown. Try again. |
| Hotkeys don't work | Some apps block global hotkeys. Click **Set Hotkeys** and choose different keys. |
| Antivirus blocks the EXE | This is a false positive. Click "More info" → "Run anyway" or add an exception. |
| Line breaks aren't working | Make sure you have actual line breaks in your text (press Enter). |
| Typing is too fast/slow | Adjust the speed setting before starting. |
| Mistakes not happening | Set Mistakes to "Many" or "Lots". |
